# ADR-013: Almacén de archivos desacoplado con URL prefirmadas

**Contexto.** Evidencias, fotos de equipos e imágenes del catálogo deben funcionar igual en local (Docker) y en AWS
(Amazon S3), sin reescribir la lógica de negocio.

**Decisión.**
- `backend/app/almacen.py` define una interfaz común con dos implementaciones: `AlmacenLocal` (disco + firma HMAC que
  emula las URL prefirmadas) y `AlmacenS3` (boto3). `ALMACEN_MODO=local|s3` elige cuál.
- La base guarda solo bucket y clave relativa, nunca URL.
- El navegador sube directo al almacén con una URL prefirmada; la API nunca recibe el binario en modo S3.
- Antes de registrar, la API verifica el archivo: tamaño, SHA-256 y ausencia de EXIF/GPS en imágenes; en archivos
  grandes solo el tamaño, para no descargar videos de 500 MB en la EC2.
- `AWS_ENDPOINT_URL` permite probar contra MinIO o LocalStack.

**Consecuencias.** Los buckets necesitan CORS para el PUT desde el navegador y no pueden restringirse solo al endpoint
de VPC. El rol de la EC2 solo tiene acceso a los dos buckets (S3EvidencePolicy).
