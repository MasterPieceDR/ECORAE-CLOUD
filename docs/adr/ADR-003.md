# ADR-003: Los catálogos son una fuente única en la base de datos

**Contexto.** Estados de trazabilidad, transiciones, clasificaciones, roles, categorías, centros y tipos de evidencia
cambian con el negocio. Si el frontend los repite, cada cambio exige tocar dos lugares y aparecen incoherencias.

**Decisión.** Todos los catálogos están en el esquema `cat` y se exponen con `api.fn_catalogos()` y `GET /api/v1/catalogos`.
El frontend los carga al iniciar sesión (`useCatalogos`) y no tiene listas escritas a mano.

**Alternativas.** Enumeraciones en el código (más simple, pero duplica la verdad) o un servicio de configuración aparte
(innecesario a esta escala).

**Consecuencias.** Agregar una categoría o un estado no requiere desplegar el frontend (RNF-05). El catálogo de modelos
de la Fase 2 (ADR-012) sigue el mismo principio.
