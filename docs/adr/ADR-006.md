# ADR-006: Asistente MCP con un solo ejecutor, bitácora y confirmación humana

**Contexto.** Se ofrece un asistente (panel web, chat con Claude y servidor MCP estándar) que puede consultar y proponer
acciones. Un modelo de lenguaje no debe poder modificar la trazabilidad por su cuenta.

**Decisión.** Las tres puertas usan el mismo ejecutor y la misma bitácora. El login `ecoraee_mcp_svc` solo ejecuta lo
registrado en `mcp.herramienta`, filtrado por el rol del usuario. Toda escritura queda «pendiente de confirmación» hasta
que una persona la aprueba.

**Alternativas.** Dar al asistente acceso directo a la API (sin control fino) o no ofrecer asistente.

**Consecuencias.** Las pruebas verifican el acceso denegado, la espera de confirmación y la bitácora. En AWS el servidor
MCP no se expone por defecto (perfil opcional en `docker-compose.aws.yml`).
