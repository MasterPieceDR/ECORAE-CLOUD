# ADR-010: Red de flujo con capacidad de nodo y cinco escenarios

**Contexto.** El enunciado pide modelar la red como un grafo dirigido con capacidades y aplicar flujo máximo y corte
mínimo (RF-MD-03 a RF-MD-05), con datos leídos de la base (RF-INT-04, CP-09).

**Decisión.** La red real del capítulo de Discretas está en el esquema `red`. La capacidad del laboratorio de evaluación
se modela dividiendo el nodo (E_in → E_out con la capacidad en esa arista). Hay cinco escenarios (E0 a E4) y la API
calcula el flujo, todos los cortes mínimos y guarda el resultado con un hash del conjunto de datos.

**Alternativas.** Capacidades solo en aristas (no representa el cuello de botella del laboratorio).

**Consecuencias.** Resultados de referencia: E0 200 · E1 225 (3 cortes) · E2 200 · E3 175 (2 cortes) · E4 280
(`math/flujo_maximo.py`). El editor de escenarios (script 13) permite borradores «qué pasaría si».
